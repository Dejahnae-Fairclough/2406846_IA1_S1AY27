Critical Essay: LLMs as a tool, not a Crutch

The statement "LLMs must be used as a tool not a crutch" means that we should use AI to help us learn, not do everything for us. If we depend on AI to write our code and solve every problem, we won't get the chance to improve our own skills or understand how things work.

I believe AI is useful when we get stuck or need help understanding something. It can explain errors and help us learn better ways to write code, but we should still try to solve problems on our own first (Mollick & Mollick, 2023). When I am doing my programming assignments, I try to write the code myself and use AI mainly when I have syntax errors or need help understanding what went wrong.
